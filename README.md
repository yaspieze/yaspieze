# Hey, I'm Yaspieze 👋
**You can call me Yaspz too!**

I'm a nerdcore artist who turns the games and shows I enjoy into music. A character, a story, or just a certain vibe can give me the idea for a song, and I take it from there.

I've been sharing music on YouTube since early 2023. I write, sing, arrange, and mix my songs myself, so each release is a personal project from start to finish.
